# Local-business multi-variant preview checks

Use this before signoff on any three-lane local-business preview.

## Hero divergence
- Each variant needs a clearly different hero composition, not only a different accent color.
- Change at least three of these: image scale, copy placement, alignment, density, CTA behavior, background treatment, type voice.
- If the three heroes can be mistaken for the same template, rebuild.
- Hero divergence is the minimum, not the finish line. If the user asked for skill-led or full-capability variants, carry at least one major differentiation below the fold too, usually in services, portfolio/trust, or contact. Otherwise the set reads like one page with five different openings.

## Finished-result imagery
- Prefer completed spaces in the hero when the business sells the finished room, not the construction phase.
- Construction-state images are supporting proof, not usually the lead promise.

## Anti-tile composition
- Do not let the page drift into equal card fields and tidy repeated rectangles.
- Proof sections should feel curated and editorial, not like a component catalog.

## Restrained project-gallery teaser placement
- When a project has its own dedicated detail page, keep the home-page teaser compact.
- Use a few precise proof images plus a clear handoff to the full project page.

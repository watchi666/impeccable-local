# Update vs replacement image strategy

Keep the existing image world when it is:
- authentic
- local
- trust-bearing
- specific to the business's real work

Replace or supplement imagery only when the existing set is:
- visibly low trust
- unrelated to the actual offer
- too weak to support the new hierarchy
- missing critical proof moments

Preferred order:
1. keep authentic project imagery
2. improve crop, sequencing, and scale
3. supplement with other real project assets
4. replace only when the current images actively hurt credibility
